Lab 172 - Configuração de infraestrutura e implantação de servidor web

Neste laboratório, pratiquei a criação de uma VPC e subnet pública, a configuração de conectividade com a internet e o provisionamento de uma instância Amazon EC2. Também utilizei User Data para instalar o Apache e publiquei uma página web acessível pelo IPv4 público.

Atividades realizadas

01

VPC e subnet pública

Criação da rede virtual, subnet, Internet Gateway e tabela de rotas para permitir conectividade externa.

02

Security Group

Configuração das regras de entrada para permitir conexões SSH na porta 22 e HTTP na porta 80.

03

Instância Amazon EC2

Provisionamento de uma instância com Amazon Linux, IPv4 público e configuração de User Data.

04

Servidor web Apache

Instalação e inicialização do Apache, publicação do arquivo projects.html e teste de acesso pelo navegador.

O que aprendi

  • Criar uma VPC e uma subnet pública com endereçamento IPv4.
  • Configurar Internet Gateway e tabela de rotas para acesso à internet.
  • Controlar o tráfego de entrada utilizando regras de Security Group.
  • Provisionar uma instância EC2 com configuração de User Data.
  • Automatizar a instalação e inicialização do Apache com comandos Linux.
  • Publicar e acessar uma aplicação web pelo endereço IPv4 público da instância.
